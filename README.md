# hectorbliss.com

Sitio estático servido por GitHub Pages (rama `main`, raíz). Push a `main` publica.

- `index.html`: landing. CSS y switch de tema claro/oscuro inline.
- `posts/`: blog generado por `build-blog.mjs` desde MongoDB (`DATABASE_URL` en un `.env` fuera del repo).
- `img/`, `blog-img/`, `favicon.png`, `CNAME`.

Operación, DNS y credenciales: ver `~/hectorbliss.com/CLAUDE.md` en la máquina de bliss (no está en el repo).
