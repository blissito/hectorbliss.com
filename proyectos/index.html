Proyectos chidos y útiles para agentes

Herramientas abiertas que uso con mis agentes todos los días. Tómalas.

ghosty-rec

Graba una sola ventana de macOS desde la terminal y el agente la edita con zooms donde pasa la acción.

ghosty-reel

Anuncios y motion graphics 3D hechos desde la terminal: Chrome captura la UI real, Blender renderiza y ffmpeg mezcla la voz.

ghostycode

Agente de código para la terminal escrito en Rust: DeepSeek V4, MCP, subagentes y sesiones que se retoman.

ghostykit

Copiloto de agente para meter dentro de tu app React: propone la acción y espera tu visto bueno antes de hacerla.

ghosty-chrome

Tu agente usa tu propio Chrome con las sesiones que ya tienes abiertas, conectado por MCP.

ghosty-lite

Agente de terminal ligero que vive en cajas efímeras y se maneja por WebSocket con ACP.

acp-agent-ui

Interfaz web para platicar con un agente que corre dentro de una microVM, hablando ACP.

acp-desde-cero

Un cliente de ACP escrito a mano en Node puro, sin dependencias. Cada commit es una lección.

Skills para agentes

Le enseñan a tu agente a usar Ghosty, EasyBits y MailMask. Se instalan con npx skills add.
